    一个 Agent 统筹所有能力：像审计项目组长——拿到任务后自主决定每个标的查到多深： 先粗筛，有信号才升级深度研判，高风险才升级控辩互搏，裁定成立才标记追责。 同一套代码，清白公司止步粗筛、高危公司一路升级——不同输入走不同编排路径，可解释、可审计（对齐手册 §8.2.3 任务规划）。

    6 ⚖️ 多 Agent 控辩互搏（对抗式研判）

    从"单 Agent 调多工具"升级为名副其实的"多 Agent 协同"：三个立场对立的 Agent 就同一套硬证据展开对抗—— 控方尽力指控、辩方为每条指控找合理经营解释（辩方越强 = 越不误报）、裁判逐条裁定并收敛。 铁律：确定性信号命中的事实、监管已认定的违规为硬事实，不可辩驳；控辩只交锋"灰色地带的解释"，裁判不得把已发生的事实辩没。

    ⚖️ 裁判 Agent · 对抗后裁定

    🔬 信号可靠性 · 自我校准案例：格力电器（000651）误报的发现与修正
    现象：初版对格力跑出"极高"档，其中"现金不生息"信号触发（1575亿货币资金仅11.6亿利息，隐含收益率0.74%）。
    根因：取数只读了资产端 INTEREST_INCOME 科目（11.6亿），漏了财务费用冲抵的 FE_INTEREST_INCOME（46.5亿）——制造业+财务公司的利息收入分列两处，导致利息被低估 6 倍。真实隐含收益率约 2.95%，资金收益健康。
    修正：取数改为两科目取较大值，更贴近真实资金收益。修正后格力降为"高"档，误报的"不生息"信号消失；同一改动对康美（真阳性）无影响，该报的仍报。
    留下的"高"档是真信号：格力"存贷双高 + 货币资金超净资产（162%）"客观存在，是市场对其类金融业务的长期公开质疑——信号如实反映，交人工复核，不定性。
    这说明什么：确定性信号可审计、可复现、可校准——误报能被逐条判据定位到具体科目并修正，这正是"规则+人工复核"相比黑盒判造假模型的核心优势。
    ⚠ 合规边界声明：本系统输出为基于公开信息的风险提示与辅助研判，标注置信度与依据来源； 不构成审计结论、投资建议，不对任何主体作违法/有罪定性，判罚与赔偿以监管、司法机关最终裁决为准。 高风险线索强制标记"需人工复核"。仅处理公开信息侧已认定案例，不介入内幕交易等需侦查权的非公开领域。 数据来源：公开年报、证监会处罚决定书、法院判决书、国家法律法规数据库官方原文。

    6 💎 价值发现（链热单体冷错配扫描 → 归属核验 → 兜底排雷）

    同一套"看穿真伪"的引擎反过来用：在一条已走热的产业链里，找"产业上真属于这条链、但估值与关注度还在低位"的标的。 不预测涨跌、不给买卖建议——机器发现错配，人做判断。当前为结构示意数据，判据逻辑确定性可复现。

    🔥 · 链温度

    ⚠ 合规边界：输出为"值得人工深看的候选 + 证据链"，不预测涨跌、不构成投资建议、不给估值数字； 归属核验默认怀疑——证据不足不放行，宁可漏掉机会，不把题材联想当真实关联。机器发现错配，人判断机会还是陷阱。

    7 📓 决策日志（现实验证：唯一能校准"判断准不准"的机制）

    不记资金流水，记"做判断当下你怎么想的"，事后对答案——防"赢了编故事"。 不用买，观察走势即可验证。前三层约束保证系统诚实，只有这一层（现实验证）检验它正确。
