# 舞弊识别方法论 —— 图灵哨兵的"审计大脑"

> 本文档是"图灵哨兵"最核心、最不可替代的 know-how 层。
> 它不来自审计教材，而来自作者一线审计的真实经历。教材写"应该做什么"，本文写"实际怎么发现问题"。
> 每一条"报警信号"都会在系统中对应一个可自动执行的检测动作（Skill），并说明它撞的是哪个独立来源。

---

## 一、核心思想:不信单一账目,用独立来源交叉"找缝"

一笔真实交易会在多个地方留下痕迹——合同、报关单、物流单、银行流水、税务、海关、水电、工商。**造假的人几乎不可能把每一处都改得天衣无缝，总有一处对不上。** 审计的功夫，就是把这些相互独立的来源摆在一起，找那条"本该一致却对不上"的缝。

这个思想与本项目的两项技术天然同构：
- **多个独立数据源** = 图上不同类型的节点与边；
- **"找对不上的地方"** = 图上的结构异常检测（GNN 主场）；
- **"自动去每个来源取数、比对、报警"** = 多 Agent 分工协作。

即：**审计直觉与图神经网络，是同一个思想的两种表达——单点合规，交叉见鬼。**

## 二、四类"矛盾武器"(源自真实案例)

| 矛盾类型 | 撞的是什么 | 案例原型 | 对应检测动作 |
|---|---|---|---|
| **物理约束反推** | 账面 ✕ 客观物理世界 | 账面存货量在物理上塞不进仓库容积 | 存货量 ✕ 仓储容积/电费/仓储费 |
| **文件互撞** | 文件 ✕ 文件 | 合同结算条款(DAP/DDP) 与 报关条款(FOB) 不一致，跨期确认收入 | 合同条款 ✕ 报关单 ✕ 收入确认时点 |
| **条款套利** | 交付时点口径操纵 | 用有利的 Incoterms 口径把明年的收入塞进今年 | Incoterms 风险转移点 ✕ 收入确认准则 |
| **资金流核对** | 账面货币资金 ✕ 银行原始流水 | 货币资金与银行对账单逐笔核对对不上，牵出挪用 | 账面资金 ✕ 银行对账单/流水 ✕ 关联方去向 |

> 说明：物理约束反推源自作者入行早期一次存货盘点（数学系出身的领导以"单件体积×堆叠方式×仓库容积"反推账面量级不可能）；文件互撞/条款套利源自装备制造业出口业务的收入跨期审计；资金流核对源自作者亲历、后经公开司法程序印证的货币资金挪用案（见主方案"项目缘起"）。

## 三、舞弊报警信号清单(持续扩充)

> 每条信号 = 一个"组合触发"规则。单个指标正常，组合出现即警觉。落地为系统的规则/Skill。

### A. 资金类（最硬、最能定性）
- 账上货币资金充裕，却仍大额借款并支付高息 → 钱可能是假的/受限/被占用（獐子岛、康美、康得新原型）
- 账面货币资金与银行对账单逐笔核对存在差额 → 挪用/体外循环/资金占用
- 大额资金在期末前后与关联方之间往返流动 → 资金空转、虚增收入配套走账

### B. 收入类
- 四季度/年末收入突击暴增，客户多为新成立、同地址、同期注册 → 虚构收入
- 收入暴增但物流单量/运费未同步增长 → 收入可能是编的
- 合同交付条款与报关/物流实际口径不一致 → 跨期确认收入（伊之密原型）

### C. 存货/成本类
- 账面存货量与仓储容积/电费/仓储费不匹配 → 存货虚增（物理反推）
- 毛利率显著高于同行且经营现金流常年为负 → 利润质量存疑
- 产量与耗电/耗材/人工不匹配 → 成本或产量造假

### D. 结构/关系类（GNN 主场）
- 与一批同地址、同一天注册的客户/供应商做大额交易 → 关联方走账
- 公司处于由担保圈/交叉持股构成的高风险结构中 → 风险传导
- 关系图上"邻居无已知问题、但交易结构异常" → 隐蔽伪装（合众思壮原型：63 个邻居无已知舞弊，靠 47 条关联方交易结构异常暴露）

## 四、独立印证来源清单(agent 的取数目标)

系统按审计视角，自动向这些**相互独立**的来源取数并交叉比对：
- 工商 / 股权穿透（识别实控人、关联方、同址同期注册）
- 关联方交易明细（图结构输入）
- 银行对账单 / 资金流水（资金核对）
- 海关报关 / 物流单据（收入与交付印证）
- 税务 / 发票（三流一致性）
- 水电 / 仓储 / 产能（物理约束反推）
- 证监会问询函 / 处罚记录 / 舆情（外部风险信号与标签）

## 五、边界声明(合规红线)

本方法论与系统仅用于**辅助识别与预警**，输出为带依据、标置信度的风险线索清单，**不构成审计结论、不替代注册会计师的专业判断与最终意见**。高风险线索一律标记"需人工复核"。数据仅使用公开数据集（如 FiGraph）、公开监管信息与合成/脱敏模拟数据，不使用任何未授权或未公开的真实业务数据。
