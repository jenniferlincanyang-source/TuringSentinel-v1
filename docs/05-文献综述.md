## 摘要

有效市场假说主张公开信息已充分反映于价格。但四十年实证金融系统性地记录了它在何处失灵：
投资者**注意力有限**，信息在关联资产间**渐进扩散**，**经济网络**上的冲击传导被市场定价不足。
本文梳理这三类市场无效的奠基文献（1999–2011），指出它们正是"链热单体冷""顺产业链找标的"
等结构性错配信号的理论根基。随后回顾 2016 年前后的"证伪潮"——多重假设检验与异象衰减研究
共同表明：依赖公开、可复现信号获取超额收益是一条越走越窄的路。这一结论把研究推向三个新前沿：
机器学习/图神经网络资产定价、另类数据、文本与大模型金融。本文进一步纳入 2024–2026 年的最新工作，
论证这波前沿（GNN 欺诈检测、可解释关系图、LLM-RAG 基本面分析、多 Agent 交易）恰与本项目
"价值发现 + 反舞弊"双主线重合。最后提出：在信号红利耗尽的时代，可持续的超额认知不来自更多信号，
而来自**别人读了论文也复制不了的能力**——本项目的答案是审计式的"看穿真伪"，落地为
确定性规则 + 关系图结构 + 归属核验的多 Agent 系统。

## 一、导论：从一个实践困惑出发

本项目起于一次真实交易的复盘：一个标的在同产业标的普遍上涨时仍被冷落，后被重估获利。
关键不是"赚到了"，而是一个审计式的自问——**这是看穿了错配，还是幸存者偏差下的事后叙事？**
要回答它，必须先弄清：市场为什么会、以及在何种条件下会对一个公开可知的事实定价错误？
这正是行为金融与实证资产定价四十年的核心问题。本文据此展开。

## 二、三类市场无效：结构性错配的理论根基

### 2.1 有限注意力（Limited Attention）

投资者的注意力与信息处理能力是稀缺资源。信息即便完全公开，也可能因"无人处理"而未被及时定价。
Hong 与 Stein（1999）的统一模型是理论源头：他们设定"新闻观察者"与"动量交易者"两类有限理性主体，
**私有信息在群体中渐进扩散**，导致价格先反应不足（短期动量）、后过度反应（长期反转）。
Da、Engelberg 与 Gao（2011）用 Google 搜索量作为散户注意力的**直接、可测代理**，
开创了"注意力可量化"的实证路径。Hirshleifer、Lim 与 Teoh（2009）则证明：
当同日有大量其他公司同时披露盈余时，投资者"分心"，对单一公司信息反应更不足——
直接坐实注意力的稀缺性与可分散性。

> **对本项目的意义（含一处重要的自我修正）**：这支文献常被误读为"买小盘、买低关注股"。
> 但它真正证明的是**信息处理有摩擦，故市场对某个已公开事实（如产业链地位、政策受益）的"认知滞后"真实存在**。
> 我们据此支撑的是**认知差**（市场还没看懂它在产业链/政策里的位置），**不是关注度差**（小盘没人看）。
> 认知滞后不分大小盘——它常发生在"大家都盯着、却都看错"的大票上。

### 2.2 信息渐进扩散与 lead-lag

信息不会瞬间反映到所有相关资产，而是先在受关注的龙头/大公司显现，再滞后传导到关联但被忽视的标的，
形成可预测的"领先—滞后"关系。Hou（2007）在《Review of Financial Studies》证明：
**同行业内大公司的股价领先小公司**，且该效应主要由信息渐进扩散驱动、集中于信息摩擦大处。

> **对本项目的意义**：这几乎是"链热单体冷"的实证版——龙头（大公司）先热，关联标的滞后。
> 它把我们的核心直觉，对应到一篇顶刊的明确发现上。

### 2.3 经济网络定价不足（Network / Supply-Chain）

企业间的供应商—客户、股权、共同持有关系构成经济网络，网络上的冲击沿链传导，而市场对此定价不足。
Cohen 与 Frazzini（2008）是与本项目关联最紧的一篇：他们用企业强制披露的主要客户
（占销售 ≥10%）识别供应链，发现**股价不能及时反映经济关联公司的消息**——
客户表现好/坏，供应商股价同向变动但**有滞后**，由此产生可预测的"客户动量"，
且该效应**集中于低分析师覆盖、低机构持股的标的**，与有限注意力完美打通。
Menzly 与 Ozbas（2010，⚠️ 卷期页码待核）将其从公司层面拓展到产业链的行业层面。
Ying（2024）进一步把"渐进扩散"延伸到"被同一批机构共同持有"的公司网络，
说明"经济网络"的定义仍在扩展——与本项目用 GNN 在多种关系边上抓结构信号的路线同源。

> **对本项目的意义**：Cohen-Frazzini 一篇同时为我们的信号族①（产业链归属）、②（反向印证）、
> ③（关系图结构）背书，证明"顺产业链找标的"有真实、可捕捉的 alpha，且根源是有限注意力。

## 三、证伪潮：为什么"堆信号"这条老路走到了尽头

一个常见困惑是"这类研究近年为何没有新东西"。答案不是不好发表，而是这个品类被两篇论文从根上动摇。

Harvey、Liu 与 Zhu（2016）把学界数十年发表的数百个因子拉出来做**多重假设检验校正**，
结论近乎羞辱：绝大多数已发表 alpha 在校正后不再显著，是海量数据挖掘的产物；
他们主张新因子的 t 值门槛应提到 3.0 以上，直接抬高了"发现新异象"的门槛。
McLean 与 Pontiff（2016）追踪 97 个异象比较发表前后收益，发现**异象公开后收益平均衰减约 58%**——
套利者读了论文即交易，把 alpha 抹平。

> **这恰是对本项目方法论的最强背书**：靠"公开可复现的信号"赚钱是一条自我消灭的路。
> 可持续的超额认知，必须来自**别人读了论文也复制不了的东西**。本项目的答案：审计式"看穿真伪"的认知，
> 它不是一个可被复制的公式，而是一套判断——这也是我们坚持"不做信号动物园"的理由。

## 四、研究前沿：搬去了哪，我们站在何处

证伪潮之后，研究从"发现新线性因子"搬到三个新战场，本项目的三个技术支柱一一对应。

**机器学习/GNN 资产定价**：Gu、Kelly 与 Xiu（2020）用树模型与神经网络在高维预测变量上做资产定价，
系统性优于线性因子，标志范式从"找一个因子"转向"在高维非线性结构里抓规律"——对应本项目的 GNN 路线。
**文本与大模型金融**：Ke、Kelly 与 Xiu（2019）从文本数据预测收益，对应本项目深度研判 Agent 读公告提红旗。
**另类数据**（⚠️ 待补权威综述）：研究重心从"用价格预测价格"转向"用价格之外的真实世界信号"——
对应本项目"顺产业链披露挖标的、上下游反向印证"。

进入 2024–2026，这条路在 **LLM Agent + GNN** 上爆发，且与本项目双主线正中心重合：
Cheng、Zou 与 Xiang（2024）的《GNN 金融欺诈检测综述》把本项目反舞弊 GNN 路线接入最新文献主线
（作者程大伟为该领域活跃学者）；Niu、Lu 与 Dolphin（2024）批评多数 GNN 选股依赖预定义静态关系图、
主张"先解释关系图再预测"，恰与本项目"用真实披露关系建图 + 归属核验做解释"呼应；
Ziółko 与 Dobrzeniewski（2026）用 RAG + GPT-4o 处理年报与 SEC 文件生成投资简报，
几乎是本项目"深度研判 + 价值发现"的美股同期同类工作。2026 年 arXiv 上
《AlphaForgeBench》《MadEvolve》《PolySwarm》等（⚠️ 仅题录核）显示，
"LLM 做因子挖掘/策略设计/多 Agent 交易"是当下最密集的前沿集群。

> **定位一句话**：时间线为 经典异象（2008）→ 证伪潮（2016）→ AI 化（2020）→ LLM/GNN 爆发（2024–2026）。
> 本项目不在捡过时 alpha，而是站在最新范式主线上，且**多了"审计认知"这层别人学不走的护城河**。

## 五、未来探索方向与作者可承担的工作

综述的终点，是回答"接下来做什么、我能做什么"。基于上述版图，给出三个层次——
按**认知优势匹配度**与**落地可行性**排序，并严格继承项目铁律：先深后广、认知差非关注度差、可核对非讲故事。

### 方向一（近期、最该做）：可解释关系图上的"归属核验"——直接回应 Niu(2024) 的学术缺口

- **学术缺口**：Niu 等（2024）指出主流 GNN 选股依赖**预定义静态关系图**、缺乏可解释性——"先解释再预测"是公开呼吁。
- **作者可做的**：本项目用**真实披露关系**（供货/股权/关联）动态建图，并以**控辩互搏的归属核验**
  给出"这条关系是真实产业关联还是题材联想"的可解释裁定。这**正好填 Niu 的缺口**，
  且有作者的审计判断力做内核——是最可能形成"可发表 + 可落地"双产出的方向。
- **可承担的工作**：在 FiGraph（[[fraud-gnn-figraph]]）或自建的 A 股产业链披露图上，
  做"结构信号 + 归属核验"的实证；对照"预定义静态图" vs "披露动态图 + 解释"的差异。

### 方向二（中期、认知护城河最深）：政策/产业结构错配的可核对化

- **学术缺口**：政策驱动的估值重估、产业结构变迁的定价滞后，实证多、但**"可核对、可复现"的系统方法少**
  （因政策解读天然主观）。
- **作者可做的**：这最贴作者关注点（产业链 ＞ 价值本质 ＞ 政策经济结构），认知含量最高、最难被量化抄走。
  但**必须套四关尺子**，尤其守"可核对"——每个判断挂到具体政策文件 + 披露，否则退化成讲故事。
- **可承担的工作**：先在**一条真正吃透的产业链 + 一项具体政策**上做闭环验证（不铺开），
  用决策日志检验"政策受益认知差"信号的真实胜率。

### 方向三（长期、天花板）：无市场价资产的公允价值——数据资产入表 / RWA

- **现实缺口**：数据资产入表（2024 施行）缺公认估值方法；RWA 上链缺可信 NAV——
  中国真实存在"给没有市场价的资产算可信公允价值"的空白（见 `愿景页_公允价值真相引擎.md`）。
- **作者可做的**：把同一台"看穿真伪、可审计、明示盲区"的引擎，沿确定性光谱右移到无市场价资产；
  **红线**：越往右证据越稀薄，越要克制——给区间 + 假设清单 + 可比，绝不给单一"公允数字"。
- **定位**：不做喂价的链（拼牌照资本的平台战争），做链缺的那箱货——独立、可审计、基于证据的公允价值本身。

### 贯穿三方向的作者独特性（为什么是"你"能做）

1. **审计一线的"看穿真伪"判断力** + 4 个真实舞弊案例方法论——别人读论文学不走的护城河；
2. **能写代码跑通真原型**（signals / GNN / 多 Agent 已落地）——不是纸上谈兵；
3. **CS + 会计交叉**的定位——恰好卡在 GNN 资产定价、可解释关系图这类"两栖"前沿的甜蜜点；
4. **审计的合规敏感度**——在一个"定价靠拍脑袋"的领域，天然做得出"判据可审计、盲区被明示"的克制系统。

> **一句收束**：信号红利的时代结束了，认知红利的时代刚开始。作者的工作，
> 不是再找一个会衰减的因子，而是把"审计式看穿真伪"这一稀缺认知，用 GNN + 多 Agent + 可核对证据，
> 做成一台能沿确定性光谱延展的公允价值引擎——**先在一条链上做深，再谈广。**
